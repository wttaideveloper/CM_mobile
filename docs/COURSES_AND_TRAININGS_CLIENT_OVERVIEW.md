# Courses & Trainings — Product Overview

**Audience:** Client / stakeholders  
**Purpose:** Simple explanation of how learners discover, enrol, learn, and complete Courses and Trainings  
**Note:** Courses and Trainings are the **same learning module**. They share the same flow and features. Only the **name** differs in the product (Course vs Training).

---

## 1. One module, two names

| Name shown to user | What it is |
| --- | --- |
| **Course** | Same learning experience |
| **Training** | Same learning experience |

Everything below applies to **both**. Screens may say “Course” or “Training,” but the behaviour is identical.

---

## 2. Where the learner finds them

Learners can discover Courses / Trainings from:

1. **Market screen** — featured / browse listings  
2. **Trainings (or Courses) listing screen** — full list with filters  

From either place, the learner **taps a card** → opens the **detail screen**.

---

## 3. Four learning types

Every Course / Training belongs to **one** of these types:

| Type | How learning works |
| --- | --- |
| **1. Live online** | Real-time sessions via **Zoom / Meet**. Learner joins at a scheduled date & time. |
| **2. Physical (venue)** | In-person at a **venue**. Learner goes to the location at the scheduled time and shows a **QR code** for check-in. |
| **3. Hybrid** | Mix of **online live** and **venue** sessions. Each session shows the correct join method (link or QR). |
| **4. Recorded / self-paced (lifetime)** | Pre-recorded videos (Udemy-style). Learner can study **anytime**. No fixed live join. Progress is based on watching / completing content and assessments. |

**Simple rule**

- Types **1–3** → usually **scheduled / fixed dates** (day & time matter).  
- Type **4** → **lifetime / on-demand** (learn when ready).

---

## 4. How content is structured

```
Course / Training
  └── Session 1
        └── Topics / lessons
              ├── Video or live / venue activity
              ├── Assignment or task (optional)
              ├── Quiz / assessment (optional)
              └── Topic PDF / download (optional)
  └── Session 2
        └── …
  └── Session N
```

**Also on the detail screen (before enrol)**

- Full **curriculum preview** (sessions + topics)  
- Course / training **documents** preview  
- Instructor, schedule, venue / delivery info  
- Price, coupons, reviews summary  

---

## 5. Before enrol — what the learner can do

On the **Course / Training detail** screen:

| Action | Allowed? |
| --- | --- |
| Browse curriculum & documents | Yes |
| Preview how learning will work | Yes |
| **Add to wishlist** | Yes |
| **Enrol / purchase** (with optional **coupon code**) | Yes |
| Download notes / PDFs meant for enrolled learners | After enrol (or as policy allows) |
| **Write a review** | **Only after enrol** |

---

## 6. Enrol flow

1. Learner opens Course / Training detail  
2. Reviews curriculum and price  
3. Applies **coupon code** if available  
4. Confirms enrol / purchase  
5. Item appears under **My Trainings / My Courses**

---

## 7. After enrol — My Trainings / My Courses

### Listing (enrolled items)

Each enrolled item shows:

- Title & type (online / physical / hybrid / recorded)  
- **Progress bar** (how much completed vs remaining)  
- Status (e.g. in progress, pending approval if needed)  

### Open an enrolled item → Learning / Progress screen

Shows:

- Overall **progress**  
- Name, instructor, and key details  
- Full list of **sessions**  

**If scheduled (live / physical / hybrid)**

- Session shows **date & time**  
- **Online session** → “Join” with meeting link  
- **Venue session** → location guidance + **QR code** for door check-in  
- After join / attendance → system can **mark attendance complete**

**If recorded / self-paced**

- Learner opens sessions anytime  
- Completes videos, topics, assignments, and quizzes at their own pace  
- No fixed join time  

**Inside sessions**

- Topics to cover  
- Assignments / tasks (when present)  
- Quizzes / exams (when present)  
- Topic PDFs to download (when present)  
- Course / training notes & documents download  

Progress updates as the learner completes content, attendance, assignments, and quizzes.

---

## 8. Completion & certificate

When the learner finishes:

- All required **sessions**  
- Required **exams / quizzes**  
- Required **assignments** (if any)  

→ They receive a **Course / Training completion certificate**.

---

## 9. Reviews

| Where | Can leave a review? |
| --- | --- |
| Course / Training **detail** screen | Yes — **only if enrolled** |
| **My Trainings / My Courses** (learning area) | Yes — **only if enrolled** |

Non-enrolled users can **read** reviews but cannot **submit** one.

---

## 10. Wishlist, purchase & materials (summary)

| Feature | Where | Notes |
| --- | --- | --- |
| Wishlist | Detail screen | Save for later |
| Purchase / enrol | Detail → checkout | Optional **coupon code** |
| Notes / PDF downloads | Detail + learning screen | Available per content rules (often after enrol) |
| Documents | Detail preview + after enrol | Curriculum-related files |
| Certificate | After full completion | Course or Training certificate |
| Reviews | Detail + My list | Enrolment required |

## 12. Quick FAQ for the client

**Q: Are Courses and Trainings different products?**  
A: No. Same module, same features. Two names in the UI.

**Q: Can someone learn a recorded course on their own schedule?**  
A: Yes. Type 4 (recorded / lifetime) is self-paced.

**Q: What if it is only at a venue?**  
A: Physical type — learner goes to the venue at the set time and uses QR for check-in.

**Q: What if some days are Zoom and some are at the venue?**  
A: Hybrid — each session shows the correct method.

**Q: When do they get a certificate?**  
A: After completing all required sessions and exams (and required assignments, if any).

**Q: Who can review?**  
A: Only enrolled learners.

**Q: Can they save something without buying?**  
A: Yes — wishlist on the detail screen.
